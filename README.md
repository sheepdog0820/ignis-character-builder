# IGNIS キャラクター作成

メタリックガーディアン向け **非公式ファン用の独自試遊ルール v2.4**（2026-10-04）で、Lv3・主熟練度2・副熟練度1のPCを作成する静的アプリです。公式クラス・公式作成規則ではありません。公式書籍本文、公式画像、シナリオ、敵、マップ、実在PCの情報を収録していません。

**[作成画面を開く](https://sheepdog0820.github.io/ignis-character-builder/)** / [GitHubリポジトリ](https://github.com/sheepdog0820/ignis-character-builder)

## 使い方

1. PC名（仮名・未入力可）を入力し、主と異なる副クラスを選びます。
2. 配布ガイドの30おすすめ構成を使うか、主2・副1の枠内で技能を入れ替え、武器を選びます。
3. 最終値、装備、攻撃、選択技能、主の共鳴解放、コア固定能力を確認します。注意表示は条件・行動枠・同種最大値を確認するためのものです。
4. 「この端末に保存」「JSONを保存」「印刷 / PDF」で保管します。JSONを読み込むと選択から最終値を再計算します。読込に失敗しても現在の入力を保持します。

クラス変更時は新しい組合せのおすすめ技能と標準装備へ切り替え、外れた選択を表示します。PC名とメモは保持します。戻る操作で入力は消えません。武器変更時は技能を保持し、使用条件を満たさなくなった技能を明示します。取得枠を超えてチェックできません。手動変更後に表示される取得例はおすすめ構成の例であり、現在の構成の行動保証ではありません。

Lv3能力値は各12、主指定能力+3、副指定能力+1（同じなら+4）。自由配分やダイス作成は使いません。Lv4以後の正式成長は各Lvごとに任意能力一つ+1ですが、この公開版の作成範囲は初期Lv3のみです。

## ローカルで動かす

アプリ実行に外部ライブラリ・外部APIは不要です。ES Modulesとデータ読込のためHTTP配信を使います。フォルダで以下を実行し、表示されたアドレスをブラウザで開きます。

```sh
python -m http.server 8765 --bind 127.0.0.1
```

`http://127.0.0.1:8765/` を開いてください。直接 `file://` で開く方法は対象外です。

Node.jsがある環境で計算テストを実行できます。

```sh
npm test
```

## データと計算

`data/rules.json` は正式原本 `rules_v2.4.json`、`equipment_v2.4.json`、主副30通りLv3選択ガイドからLv3に必要な独自データだけを抽出したものです。性能数値は変更していません。抽出元のSHA-256は `data/provenance.json` に記録します。旧任意4武器v0.1とLv4以後の作成は対象外です。

`engine.js` が計算・装備許可・タグ適合・取得条件を担当し、`app.js` が表示と端末保存を担当します。最終値は基礎・機体・主・副・装備の五段階を一度ずつ加算します。制御武器の攻撃限定+2はその武器の攻撃欄へだけ表示し、命中などの全体値には加算しません。

`tests/reference-values.json` は正式Python計算コードの全30構成と完成サンプル3構成から**数値だけ**を抽出した照合値です。人物名・物語・GM資料は含みません。

## 個人データの扱い

入力はブラウザ内で扱います。サーバー保存、ログイン、分析トラッキング、外部API送信はありません。端末保存はこのサイトのブラウザ保存領域です。別端末・別ブラウザ・別URLには引き継がれません。保存領域の消去・プライベートブラウジング・容量制限で失われる場合があるため、JSONで控えを保管してください。JSONと印刷シートには入力したPC名・メモが含まれます。

保存は保存ボタンを押した時点で行います。次回訪問時は保存済みデータを自動復元します。現在の編集内容を「端末保存を復元」や「JSONを読み込む」で入れ替えると、保存前の編集内容は置き換わります。共有端末では仮名を使い、不要な個人情報を書かないでください。

ホスティング側のアクセスログはアプリの入力保存とは別です。[GitHub公式説明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)によると、GitHub Pagesはセキュリティ目的で訪問者のIPアドレスを記録します。

## 検証の範囲

自動テストは全30構成の能力・ボーナス・計算内訳・最終値・属性防御、完成サンプル、取得枠、副許可、重複、主限定武器、適合タグ、制御武器補正、射程、共鳴と復帰、JSONの往復と不正入力を検証します。詳細な実行結果は `TEST_RESULTS.md` を参照してください。

このアプリは作成支援です。位置、射線、同意、実効防護、条件標定の発動、戦闘中の代償と回数消費、加護との接続は自動裁定しません。全文の技能条件を確認し、GMと相談してください。行動枠競合は取得禁止ではなく使用時の注意です。現在の装備で使えない技能がある場合は確認エラーを表示します。選択途中の少ない技能数は未完成として扱い、合法な下書きは保存可能です。

公式完全互換、全30構成の実戦勝率、実卓バランス、Lv4以後のUI、すべてのブラウザ・OS・プリンターでの動作は未保証です。
